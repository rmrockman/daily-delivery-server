    ⭐ แต้มและเลเวล

    อัตราแต้มต่อหมวด: ทุก (กี่ชิ้น) ได้ (กี่แต้ม) · หมวดที่ไม่อยู่ในรายการจะไม่ได้แต้ม

    เลเวล (คิดจากแต้มสะสม ไม่ลดตอนสมาชิกแลกของ)

    ของที่ส่งก่อนเริ่มระบบแต้มจะไม่มีแต้ม กดปุ่มนี้เพื่อนับย้อนหลังจากประวัติเดิมให้สมาชิกที่อนุมัติแล้ว (ชื่อในเกมต้องตรงกับประวัติ กดซ้ำได้ ไม่นับซ้ำ)

    🎯 เป้าหมายแคลน

    ทั้งแคลนช่วยกันส่งให้ครบเป้า ครบแล้วแจกแต้มให้ทุกคนที่ร่วมส่งอัตโนมัติ · นับเฉพาะรายการที่อนุมัติแล้ว

    📜 ภารกิจ

    ภารกิจรายคน ทำครบได้แต้มทันทีหลังอนุมัติ · แบบรายสัปดาห์รีเซ็ตทุกวันจันทร์ ทำซ้ำได้ทุกสัปดาห์

    🔥 อีเวนต์แต้มคูณ

    ส่งของในช่วงอีเวนต์ได้แต้มคูณ นับตามเวลาที่สมาชิกกดส่ง (อนุมัติทีหลังก็ได้แต้มคูณ) · หน้าสมาชิกจะมีป้ายนับถอยหลังขึ้นเอง

    รายการอีเวนต์

    🎖️ Discord: ประกาศเลเวลอัพ + ยศอัตโนมัติ

    ทำทีละขั้นจากบนลงล่าง ขั้นที่เสร็จแล้วจะมีเครื่องหมาย ✅

    1. ห้องประกาศเลเวลอัพใส่ลิงก์ห้อง “🎉 ห้องประกาศ” ในเมนู 🔗 Webhook
    2. เชิญบอทเข้าเซิร์ฟเวอร์Developer Portal → แอปของคุณ → General Information → คัดลอก Application ID
      🤖 เชิญบอท (สิทธิ์จัดการยศ)
      หลังเชิญ: ตั้งค่าเซิร์ฟเวอร์ → บทบาท → ลากยศของบอทให้อยู่ เหนือ ยศเลเวลทุกอัน
    3. Server IDDiscord → ตั้งค่าผู้ใช้ → ขั้นสูง → เปิด โหมดนักพัฒนา → กดค้างที่ชื่อเซิร์ฟเวอร์ → คัดลอก ID เซิร์ฟเวอร์
    4. ฟังก์ชันแจกยศ (ทำครั้งเดียว)Supabase (RM CLAN) → Edge Functions → Deploy new function → Via Editor → ตั้งชื่อ discord-roles → วางโค้ด discord-roles.ts → Deploy → แท็บ Settings ปิด Verify JWT → Secrets เพิ่ม 2 ตัวนี้
      ROLE_KEY
      DISCORD_BOT_TOKENToken ของบอท (Developer Portal → Bot)
      ลิงก์ฟังก์ชัน (แก้ถ้า Supabase ตั้งชื่อให้ต่างจากนี้)
    5. ใส่ Role ID ให้แต่ละเลเวลกดเมนู ⭐ แต้ม & เลเวล ด้านบน: Discord → ตั้งค่าเซิร์ฟเวอร์ → บทบาท → กดค้างที่ยศ → คัดลอก ID แล้ววางในช่อง 🎖️ ของเลเวลนั้น → บันทึกเลเวล
    6. เปิดใช้งาน

    📨 แจ้งเตือนสมาชิกทาง DM

    บอทจะส่งข้อความส่วนตัวหาสมาชิกเมื่อ: อนุมัติ/ปฏิเสธการส่งของ (บอกแต้มที่ได้) · อนุมัติบัญชี · มอบของรางวัล/ยกเลิกการแลก · อนุมัติ/ปฏิเสธคำขอเบิกของ · ได้อันดับประจำเดือน

    1. อัปเดตโค้ดบอท (ทำครั้งเดียว)Supabase (RM CLAN) → Edge Functions → กดฟังก์ชัน discord-roles → แท็บ Code → ลบโค้ดเก่าทั้งหมด → วางโค้ด discord-roles.ts ตัวใหม่ → Deploy
      เปิดหน้า Edge Functions
    2. ทดสอบส่ง DM หาตัวเองกดส่ง รอ 5 วินาที แล้วกดตรวจผล ควรได้ DM จากบอทใน Discord
    3. เปิดใช้งาน ถ้าสมาชิกคนไหนไม่ได้ DM แปลว่าเขาปิดรับข้อความจากคนในเซิร์ฟเวอร์ (Discord → ตั้งค่าเซิร์ฟเวอร์ → ความเป็นส่วนตัว → เปิด “ข้อความส่วนตัว”)
